# SoLaGe Project （二次元ソーシャルゲームのデザイン手法を用いた、学習活動のゲーミフィケーション研究）

(Work in Progress)

## 要旨

近年隆盛を誇っている二次元ソーシャルゲームのデザイン手法を用いて、語学学習、あるいはその他数学や国語などの教科学習をゲーム化することはできないか？

## 根底思想：心理的快楽主義

本プロジェクトの根底には、意志力や使命感といった内発的な強制力に依存せず、キャラクターへの愛着やガチャ的な快楽刺激などの**心理的な快楽を直接の駆動力として学習・創作行動を誘導する**という設計思想（心理的快楽主義）がある。

ソーシャルゲームにおいてユーザの依存を強めるために用いられる各種デザイン（いわゆる「ダークパターン」や「Hook Model（習慣化のデザイン）」）を、学習という善き目的のために転用する、という発想である。

この思想は語学学習に限らず、将来的には音楽・将棋・イラスト制作等、他分野への展開（roadmap.mdの「究極的目標」参照）にも共通して適用される。

## 具体的には

ここで「二次元ソーシャルゲーム」は「ソーシャルゲーム」と峻別される。

ソーシャルゲームを用いた学習活動の<ruby><rp>|</rp>ゲーム化<rp>《</rp><rt>ゲーミフィケーション</rt><rp>》</rp></ruby>にはすでに大規模な先行例としてDuolingoが存在する。

本プロジェクトにおいて「二次元ソーシャルゲーム」とは、「Fate/Grand Order」「ブルーアーカイブ」「学園アイドルマスター」などを筆頭とした、<ruby><rp>|</rp>二次元<rp>《</rp><rt>er ci yuan</rt><rp>》</rp></ruby>[^1]的な、所謂オタク文化と深く結びついたソーシャルゲームのことを指すものとする。

[^1]: 中国語圏では、数学・物理学的な意味での2次元を「二维」と表記する。したがって「二次元」という単語は、日本のオタク用語から派生した借用語として、専らアニメやゲームなどのサブカルチャー文化を指す概念として用いられている。以下、「二次元」という語が出てきた場合は中国語のそれに相当する概念を指すものとする。

二次元ソーシャルゲームによるゲーミフィケーションについては先行例と呼べそうなものとして「エンジニア騎士とクエリの魔女」[^paiza]や「英語物語」[^eigomono]などが挙げられるものの、この後に述べるようなデザインを完全に満たしているとはいいがたい。

[^paiza]: paiza．“DBエンジニア、魔法使いになる【プログラミングゲーム】”．2026/05/21/．https://ppg.paiza.jp/code_and_sql ．（2026-05-21）．

[^eigomono]: 株式会社FreCre．“英語物語｜遊んで英語を勉強できるアプリ！ 英語物語公式ウェブサイト”．英語物語.com．2026/05/21/．https://eigomonogatari.com ．（2026-05-21）．

### 二次元ソーシャルゲームの特徴づけ

1. ユーザの欲求を刺激するような二次元的造形のキャラクターデザイン
2. インターネットを通じてシームレスに更新されていくコンテンツ
   1. 恒常開催のメインクエストと、期間限定開催のイベントクエスト
      1. **ノベルゲーム形式のストーリーコンテンツ**
      2. ストーリー展開に付随した戦闘クエストなどのインタラクティブな要素
3. キャラクターへの愛着を強化する各種システム
   1. キャラクターごとのストーリー
   2. ガチャシステム
   3. キャラクターに焦点をあてたイベントの開催
4. ユーザの離脱を防ぐための各種システム
   1. デイリーミッションをはじめとした各種ミッションとそれによる報酬
   2. ユーザ間の交流を促進するギルドシステム

### ゲーミフィケーションの方案

上に挙げた特徴はすべて学習活動における各要素で置換できるのではないか、というのが本プロジェクトの主旨である。

1. 学習をともにする仲間（ユーザの欲求を刺激するような二次元的造形のキャラクターデザイン）
2. （インターネットを通じてシームレスに更新されていくコンテンツ）
   1. 順番に履修していく授業と、定期的に新規で開かれる模擬試験（恒常開催のメインクエストと、期間限定開催のイベントクエスト）
      1. 教科書などでもよくある、キャラクター同士が勉強会をしている風に会話している様子（ノベルゲーム形式のストーリーコンテンツ）
      2. 説明のあいまに挟まる例題や演習問題（ストーリー展開に付随した戦闘クエストなどのインタラクティブな要素）
3. キャラクターへの愛着を強化する各種システム
   1. 学習仲間との知識の深め合いのようす（キャラクターごとのストーリー）
   2. 特定分野の知識が豊富な学習仲間の獲得（ガチャシステム）
   3. 学習者の悩みなどに焦点をあてたストーリー（キャラクターに焦点をあてたイベントの開催）
4. （ユーザの離脱を防ぐための各種システム）
   1. 毎日行うことで定着を図るべき単語学習や計算演習（デイリーミッションをはじめとした各種ミッションとそれによる報酬）
   2. 学習者同士での自主的な勉強会（ユーザ間の交流を促進するギルドシステム）

## 研究計画

まずはDuolingoという巨大な先行研究から本プロジェクトへ応用できる研究成果がないか探る。

そのうえで、上に挙げたようなデザイン、あるいはそのほかのデザインが学習活動へ及ぼす効果について仮説を構築する。

実装段階の初期では、PoC（概念検証、プロトタイプ）として語学学習に焦点をあてた小規模なアプリケーションを作成する。単語学習については記憶心理学の成果が利用できる。

具体的に研究成果とすべく、ユーザのプレイデータを同意付きで取得し、ABテスト（介入検証）を通じて統計学的な効果検証を行う。


### なにがいいたいのか

というか、なにがつくりたいのか、というと、つまり

- 中国語・韓国語入門ソシャゲ
  - これだけ中国・韓国発のソシャゲが増えているので、文化交流の円滑化の観点からみても、ソシャゲで勉強できるようにしてくれよ、と切に願う
- 圏論入門ソシャゲ
   - 圏論は関連分野が多岐すぎて一冊の本に収めることは到底できないので、そもそもノベルゲーム形式と相性がいい
   - NaturalNumberGameのようにして、証明や計算の演習をゲーム化すればよい？
- おえかきソシャゲ
   - 直線や曲線の引き方、パースの練習、模写、といった地道な努力を要する部分はぜったいゲーム化して楽しみながらやれるようにしたほうがいい、というか、しないといけない
   - つくった作品をゲーム内・ゲーム外SNSで発表してそれへの評価がゲーム内通貨になったらうれしいよね
      - これはむしろ原義的な"Social Game"に近いかもしれない
- 受験勉強のソシャゲ化
   - 受験産業をぶっこわす！「ソシャゲやってたら京大受かりました」が理想
   - 受験勉強はほんとうにゲームに似ているので、ゲームにしたほうがいい！

ちょっとしたお気持ち表明：

著名なアニメなどを指して「オタクの義務教育」と言ったりするが、義務教育と称するなら、無料でのアクセスは担保してくれよ、と思う。その点ソシャゲというのはストーリー等へのアクセスは基本無料であるから「義務教育」としてもそこまで問題はないであろう。
するとむしろ、義務教育をソシャゲによってオタクコンテンツ化するべきではないか？そして、焦点を絞ることにより、より高い学習補助効果が得られるようになるのではないか？
